# ChromaTruth: Deepfake Detection through Chromatic Reconstruction Inconsistencies

ChromaTruth is an experimental deep learning pipeline for detecting facial image manipulations through **chromatic reconstruction inconsistencies**.

Instead of training a conventional binary classifier directly on *Real vs. Fake* images, the approach models the chromatic structure of genuine human faces. A colorization network is trained exclusively on real facial images and learns to reconstruct chrominance from luminance.

The central hypothesis is that digitally manipulated facial images may introduce subtle inconsistencies between image structure and color. These inconsistencies can be revealed through reconstruction errors generated by a model that has learned only from genuine faces.

The project was developed as part of the **Neural Networks and Deep Learning** course of the BSc in Artificial Intelligence and Data Science at the University of Beira Interior.

---

## Project Overview

The pipeline follows four main stages:

1. **Real face dataset preparation**
2. **Synthetic manipulation generation with Stable Diffusion inpainting**
3. **Self-supervised face colorization using a U-Net**
4. **Deepfake detection through chromatic reconstruction error analysis**

The final system generates:

- chromatic reconstruction error maps;
- explainability heatmaps;
- multiple detection scores;
- ROC curves and AUC-ROC evaluation;
- threshold-based classification metrics.

The best experimental configuration achieved:

> **AUC-ROC ≈ 0.7627**

---

## Motivation

Traditional deepfake detectors often learn artifacts or fingerprints associated with specific generative architectures.

This can become problematic as image generation techniques evolve. Modern diffusion models and advanced inpainting systems can produce highly realistic manipulations with fewer obvious visual artifacts.

ChromaTruth explores a different idea:

> Instead of learning what makes an image fake, learn what makes a real face chromatically coherent.

A genuine facial image contains relationships between:

- **Luminance** — image structure and illumination;
- **Chrominance** — color information.

The project investigates whether facial manipulation disrupts these relationships enough to produce measurable reconstruction errors.

---

## Core Hypothesis

Images are converted from RGB to the **CIELAB color space**.

The Lab representation separates image information into:

- **L** — luminance;
- **a** — green/red chromatic component;
- **b** — blue/yellow chromatic component.

The model receives only the **L channel** and learns to reconstruct the **a and b channels**.

Because the network is trained exclusively on genuine faces, it learns regularities associated with natural facial color distributions.

For a manipulated image, the reconstructed chrominance may differ more strongly from the original chrominance.

For each pixel, the reconstruction error is calculated as:

```text
E = ||ab_predicted - ab_original||₂
```

The resulting error map is then analyzed to determine whether the image presents abnormal chromatic inconsistencies.

## Dataset

The project uses the **Flickr-Faces-HQ (FFHQ)** dataset as the source of genuine facial images.

A total of:

```text
52,001 real facial images
```

were considered in the original experimental setup.

The dataset was divided using a fixed random seed for reproducibility:

```text
Training: 41,600 images (80%)
Testing:  10,401 images (20%)
Seed:     42
```

The model used for color reconstruction is trained only on real images.

The FFHQ dataset itself is **not included in this repository**.

---

## Synthetic Manipulation Generation

To create manipulated facial images, the project uses **Stable Diffusion Inpainting** through the Hugging Face Diffusers library.

For each selected genuine face:

1. a facial region is selected;
2. a mask is generated;
3. Stable Diffusion modifies the masked region;
4. the generated image is stored using the same filename as its real counterpart.

This produces paired samples:

```text
Real image → Manipulated image
```

The inpainting pipeline uses prompts designed to preserve photographic realism.

Example configuration:

```text
Model: runwayml/stable-diffusion-inpainting
Inference steps: 12
Guidance scale: 5.5
Strength: 0.65
Seed: 123
```

During experimentation, different numbers of manipulated images were evaluated:

```text
3,000
6,000
12,000
```

The final reported experimental configuration used **6,000 manipulated images**.

## Colorization Model

The core reconstruction model is a lightweight **U-Net** implemented in PyTorch.

### Input

```text
L channel
Shape: 1 × H × W
```

### Output

```text
a and b channels
Shape: 2 × H × W
```

The architecture contains:

- convolutional encoder blocks;
- max-pooling;
- bottleneck representation;
- transposed convolutions;
- skip connections;
- final two-channel chrominance prediction.

The final layer uses `tanh`, matching the normalized chrominance range.

---

## Image Preprocessing

Images are resized to:

```text
256 × 256
```

RGB images are converted to Lab using OpenCV.

Normalization:

```python
L  = lab[..., 0:1] / 255.0
ab = (lab[..., 1:3] - 128.0) / 128.0
```

This produces:

```text
L  ∈ [0, 1]
ab ≈ [-1, 1]
```

## Training

The current implementation includes:

- PyTorch;
- GPU acceleration through CUDA when available;
- automatic mixed precision;
- Smooth L1 reconstruction loss;
- AdamW optimizer;
- learning-rate scheduling;
- early stopping;
- automatic checkpoint saving.

The best model is stored as:

```text
outputs/colorizer/best_colorizer.pt
```

The model is selected according to validation loss.

## Deepfake Detection

Once the colorization model has been trained, both real and manipulated images are passed through the network.

For each image:

```text
RGB image
   ↓
Lab conversion
   ↓
L channel
   ↓
U-Net
   ↓
Predicted ab channels
   ↓
Comparison with original ab
   ↓
Chromatic reconstruction error map
```

The error map represents the difference between the original chrominance and the chrominance predicted by the model.

Manipulated images are expected to produce less consistent reconstruction patterns.

---

## Detection Scores

Several strategies were evaluated for transforming reconstruction error maps into discriminative scores.

These included:

### High-percentile error

A high percentile of the reconstruction-error distribution.

### Top-1% mean

The mean reconstruction error among the highest-error pixels.

### Composite score

Combination of several error statistics.

### Error ratio

Comparison between reconstruction statistics of paired real and manipulated images.

### Peak ratio

Measures differences between extreme regions of the error distribution.

### Fused score

Combination of multiple detection signals.

### Score Mix

The final experimental score combines:

```text
log reconstruction-error ratio
+
λ × top-error difference
```

with:

```text
λ = 0.9
```

Several high-percentile values were evaluated.

The best-performing region was approximately:

```text
PHIGH = 82–85
```

with the final reported configuration using:

```text
PHIGH = 85
```

## Explainability and Heatmaps

The project also provides qualitative visual explanations of reconstruction errors.

Heatmaps are generated from the chromatic error maps and overlaid on the original image.

The visualization pipeline includes:

- percentile-based normalization;
- Gaussian smoothing;
- thresholding;
- morphological dilation;
- connected-component analysis;
- optional bounding boxes;
- heatmap overlay generation.

Example conceptual output:

```text
Original image
      ↓
Chromatic reconstruction
      ↓
Error map
      ↓
Heatmap
      ↓
Potentially inconsistent regions
```

The experiments showed that manipulated images often produced stronger and less spatially homogeneous chromatic errors.

An important observation was that useful reconstruction error was not always restricted to the facial region. Hair, facial boundaries and nearby background regions could also contain relevant signal.

---

## Facial Mask Experiments

An additional experiment restricted reconstruction-error analysis to the manipulated facial region using masks.

Although this initially appeared intuitive, the masked version consistently produced worse results.

The analysis suggested that contextual chromatic information outside the strictly manipulated region also contributes to discrimination.

For this reason, the final experimental configuration used **global reconstruction-error statistics rather than facial-mask-restricted statistics**.

---

## Evaluation

The main evaluation metric is:

```text
AUC-ROC
```

This metric was selected because it evaluates discriminative ability independently of a fixed classification threshold.

The best reported experimental configuration achieved:

```text
AUC-ROC ≈ 0.7627
```

Threshold-based evaluation is implemented separately.

The evaluation pipeline calculates:

- Accuracy;
- Precision;
- Recall;
- F1-score;
- F2-score;
- confusion matrix.

A dedicated calibration split is used to select the decision threshold before evaluating it on a separate evaluation subset.

---

## Experimental Design

One important design decision was separating:

### Discriminative evaluation

Implemented through:

```text
test_auc_coluna.py
```

This compares different scoring strategies using AUC-ROC.

### Binary decision evaluation

Implemented through:

```text
evaluate_threshold.py
```

This selects a classification threshold using a calibration subset and evaluates the selected threshold on a separate evaluation subset.

This separation prevents the decision threshold from directly influencing the comparison between scoring functions.

## Main Files

### `config.py`

Defines project paths, experiment names, dataset directories and shared configuration.

### `make_splits.py`

Creates deterministic training and testing partitions from the original real-image dataset.

### `generate_fakes_inpainting.py`

Generates manipulated facial images using Stable Diffusion inpainting and stores the corresponding masks.

### `train_colorizer.py`

Implements and trains the U-Net colorization model using genuine facial images.

### `build_pairs.py`

Creates the mapping between each genuine image and its manipulated counterpart.

### `detect_and_xai.py`

Runs reconstruction, calculates chromatic error maps, computes detection scores and generates explainability heatmaps.

Compares the discriminative performance of multiple detection scores using AUC-ROC.

### `evaluate_threshold.py`

Performs threshold calibration and evaluates binary classification performance.

### `logger_utils.py`

## Results

The strongest experimental configuration obtained:

| Metric | Result |
|---|---:|
| AUC-ROC | **≈ 0.7627** |
| High percentile | **85** |
| Score weight λ | **0.9** |
| Final manipulated set | **6,000 images** |

The experiments also produced several qualitative findings:

- intermediate percentiles were more robust than extreme percentiles;
- facial masking reduced detection performance;
- reconstruction inconsistencies were often spatially distributed;
- manipulated images tended to show stronger and less homogeneous chromatic reconstruction errors;
- increasing the manipulated dataset from 3,000 to 6,000 images improved performance;
- increasing it further to 12,000 images did not produce consistent additional gains.

## Limitations

ChromaTruth is an **experimental research project**, not a production-ready deepfake detector.

Several limitations should be considered.

### Paired evaluation

The strongest reported score uses information derived from corresponding real/manipulated image pairs.

Therefore, the reported AUC should be interpreted as the performance of the experimental paired evaluation strategy rather than a fully independent single-image production detector.

### Manipulation domain

The final experiments focus primarily on **Stable Diffusion facial inpainting**.

Performance on other manipulation methods such as:

- face swaps;
- GAN-generated faces;
- other diffusion models;
- video deepfakes;

has not been comprehensively evaluated.

### Dataset domain

Training and evaluation are based on FFHQ facial images.

Generalization to different acquisition conditions, resolutions, demographics and real-world image distributions requires further study.

### Computational requirements

Generating thousands of Stable Diffusion samples and training the colorization model can be computationally expensive.
